# Zirk

**Screenshots and screen recording for Windows.** Select an area, a window or the whole screen,
capture a long page with scrolling, record a short MP4, mark it up and paste it anywhere.

[Українською ↓](#українською)

**[⬇ Download the latest version](https://github.com/ihor-kostiuk-hue/zirk-releases/releases/latest)** (`Zirk_…_x64-setup.exe`)

## What it does

- **Capture**: area, window (clean, without what covers it), full screen, or a **scrolling
  capture** of a long page (manual or auto-scroll). One hotkey, `Ctrl` `Shift` `1`, opens the
  selection; switch modes in the bar at the top with `1`–`5`.
- **Record video**: MP4 at 30 fps with the cursor, an optional countdown and trimming. It pastes
  into Telegram, Slack and the like as a file.
- **Annotate**: arrows, lines, shapes, text, numbered steps, highlighter, spotlight, and hiding of
  sensitive parts (pixelate, blur or solid fill). Crop with aspect presets, a nice background,
  undo / redo.
- **After a capture**: a thumbnail in the corner of the screen. Copy, save, open in the editor,
  or drag it straight into another app.
- **Recent captures**: left-click the tray icon to see the last 20 screenshots and videos.
- Light and dark theme, Ukrainian and English. You can set a hotkey for every mode.

## Install

1. Run `Zirk_…_x64-setup.exe`. No administrator rights are needed.
2. If Windows shows “Windows protected your PC”, click **More info → Run anyway**. Zirk is not
   code-signed yet.
3. Zirk lives in the system tray (it may be hidden under the **^** arrow). Press `Ctrl` `Shift` `1`
   to take a screenshot.

**Updates are automatic.** When a new version is out, the tray panel shows an **Update** button.
To check right away, open Settings → Updates → Check.

**Requirements**: Windows 10 or 11, 64-bit. Video recording on Windows N / KN editions needs the
Media Feature Pack (Zirk tells you how to install it).

**Privacy**: captures and history stay on your computer. The only network request is the update
check against this repository.

**Something wrong?** Go to Settings → Report a problem. Send the author a short description, the
version and the `zirk.log` file.

## Українською

**Скріншоти й запис екрана для Windows.** Можна виділити область, вікно чи весь екран, зняти довгу
сторінку зі скролом або записати коротке відео MP4. Потім розмітити й вставити куди завгодно.

**[⬇ Завантажити останню версію](https://github.com/ihor-kostiuk-hue/zirk-releases/releases/latest)** (`Zirk_…_x64-setup.exe`)

## Що вміє

- **Знімок**: область, вікно (чисто, без того, що його перекриває), весь екран або **знімок зі
  скролом** довгої сторінки (вручну чи з автопрокруткою). Виділення відкриває одна клавіша
  `Ctrl` `Shift` `1`, а режим перемикається на панелі вгорі клавішами `1`–`5`.
- **Запис відео**: MP4, 30 кадрів/с, з курсором, з відліком перед стартом і обрізкою. У Telegram,
  Slack тощо вставляється файлом.
- **Розмітка**: стрілки, лінії, фігури, текст, нумеровані кроки, маркер, прожектор і приховування
  чутливого (пікселізація, розмиття чи заливка). Є кадрування з пропорціями, гарний фон,
  undo / redo.
- **Після знімка** в куті екрана з'являється мініатюра. Її можна скопіювати, зберегти, відкрити в
  редакторі або перетягнути просто в іншу програму.
- **Останні знімки**: клік по іконці в треї показує 20 останніх скріншотів і відео.
- Світла й темна тема, українська й англійська мови. На кожен режим можна призначити свою клавішу.

## Встановлення

1. Запусти `Zirk_…_x64-setup.exe`. Права адміністратора не потрібні.
2. Якщо Windows покаже «Windows захистила ваш ПК», натисни **Докладніше → Однаково запустити**.
   Zirk поки не підписаний сертифікатом.
3. Zirk живе в треї (іконка може ховатися під стрілкою **^**). Знімок — `Ctrl` `Shift` `1`.

**Оновлюється сам.** Коли вийде нова версія, у панелі трею з'явиться кнопка **«Оновити»**.
Щоб перевірити одразу, відкрий Налаштування → Оновлення → «Перевірити».

**Вимоги**: Windows 10 або 11, 64-біт. Для запису відео у Windows N / KN потрібен Media Feature
Pack (Zirk підкаже, як його поставити).

**Приватність**: знімки й історія лишаються на твоєму комп'ютері. Єдиний запит у мережу —
перевірка оновлень у цьому репозиторії.

**Щось не так?** Налаштування → «Повідомити про проблему». Надішли автору опис, версію і файл
`zirk.log`.
