# Zirk

Утиліта для скріншотів і запису екрана під Windows: виділення області, вікна чи всього екрана,
знімок зі скролом, відео MP4 і редактор анотацій (стрілки, текст, лічильники, маркер,
приховування, прожектор).

## Завантажити

**[Остання версія →](https://github.com/ihor-kostiuk-hue/zirk-releases/releases/latest)**
— файл `Zirk_…_x64-setup.exe`.

1. Запусти інсталятор. Права адміністратора не потрібні.
2. Якщо Windows покаже «Windows захистила ваш ПК» — натисни «Докладніше» → «Однаково запустити»
   (застосунок поки не підписаний сертифікатом).
3. Zirk живе в треї. Знімок — `Ctrl` `Shift` `1`.

Далі Zirk оновлюється сам: коли вийде нова версія, у панелі трею з'явиться кнопка «Оновити».
